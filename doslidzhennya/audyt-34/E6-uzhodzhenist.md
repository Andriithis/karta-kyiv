# Е6. Узгодженість подачі — одне місце, одні числа

Знімки Андрія 20.10 (пл. Вокзальна, 1; вул. Георгія Кірпи, 5; вул. Олени
Теліги, 31/1). Розбір і код — центральний чат. Вимога Андрія: **усі способи
подачі (підказка, картка адреси, картка проблеми, сота, кільце, колір) не
суперечать один одному, на всіх картках усе однаково.**

## Суперечності на знімках — причина в коді

| # | Що бачить слухач | Причина | Стан |

## Рішення центрального чату (технічні; RISHENNYA 36.23 — внести виконавцю)

1. **Одне джерело правди для місця.** Число подій, види, колір і ризик
   місця (адреси, соти, кільця) рахує **одна функція** за поточним фільтром.
   Підказка, картка й сота беруть звідти, а не рахують кожна по-своєму.
2. **Клік по адресі — картка адреси з усіма подіями** (36.18.1). Число в
   картці дорівнює числу в підказці. Проблема — блоком усередині: вид,
   сценарій, «40 з 307». Окрема картка проблеми відкривається з цього блоку.
3. **Колір місця — одне правило всюди:**
   - якщо на місці є проблема, колір — вид проблеми;
   - якщо немає — вид, якого подій найбільше за поточним фільтром.

   Однаково для кола адреси, кільця, соти й 3D. Легенда — та сама.
4. **Ризик у картках — одне правило:** «Ризик: N вулиць поруч» — лінії
   ризику увімкнених видів у межах місця (адреса — 50 м, сота — її межі).
   Якщо N = 0, рядка немає. Речення «вулиці в переліку немає» прибрати (36.2:
   без пояснювальних речень).
5. **Голос мешканців (1551)** — рядок лише тоді, коли 1551 вимірює цей вид
   («підтверджують …», «мовчать …»). «Не вимірюється» не показувати. Вкладка
   «Скарги» лишається для будь-якої адреси, як вирішено 07.10.
6. **Автоматична перевірка узгодженості** (`check_build`, Playwright на
   зібраній карті): 300 випадкових місць у кожному вигляді (адреси, соти,
   кільця) і 50 проблем. Для кожного:
   - число в підказці = число в картці = сума видів у картці;
   - колір кола = колір у картці;
   - ризик у картці адреси = ризик у картці соти для тієї самої точки.

   Будь-яка розбіжність — червона збірка з переліком.

## Повний реєстр «що де показано» (для виконавця, перша хвиля)

Перед правками — таблиця всіх способів подачі:
- підказка;
- картка адреси, проблеми, соти, кільця, лінії ризику, точки ризику;
- легенда;
- смуга часу;
- пошук.

По кожному — які числа, кольори й речення показує, з якої функції. Кожна пара,
що показує те саме різним способом, зводиться до однієї функції.
