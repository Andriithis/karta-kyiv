# Карта правопорушень Києва за даними ЄДРСР

**Карта:** https://andriithis.github.io/karta-kyiv/

## Що це й для кого

Навчальний некомерційний інструмент Академії патрульної поліції для курсу
«Взаємодія з населенням на засадах партнерства». Слухачі й дільничні
офіцери обирають на карті місце, де правопорушення повторюються,
дивляться, з чого складається проблема і що поруч, і йдуть перевіряти її
на місці разом із тими, хто цим місцем опікується (балансоутримувач,
ОСББ, громада). Карта — початок розмови, а не висновок.

## Звідки дані — лише відкриті джерела

| Дані | Джерело |
|---|---|
| Правопорушення: стаття, дата, адреса з тексту рішення | Єдиний державний реєстр судових рішень (Державна судова адміністрація, [data.gov.ua](https://data.gov.ua/organization/derzhavna-sudova-administratsiia-ukrayiny)) |
| Вулиці, будинки, доріжки, заклади, зупинки | OpenStreetMap ([Geofabrik](https://download.geofabrik.de/europe/ukraine.html), щомісячний знімок) |
| Координати будинків, яких немає в OSM | Геокодер КМДА (`gisserver.kyivcity.gov.ua`, шар «Адреси») |
| Скарги мешканців | Контактний центр 1551 ([data.1551.gov.ua](https://data.1551.gov.ua)) |
| Населення | Kontur Population ([HDX](https://data.humdata.org/dataset/kontur-population-ukraine)) |
| Перевірка моделі потоку людей | Пасажиропотік станцій метро 2017 (Вікіпедія за даними метрополітену) |

Сторони в реєстрі знеособлені самим судом. На карту йдуть вулиця, номер
будинку, дата, година, стаття й короткий витяг обставин події. На карті
всі правопорушення з точною адресою, зокрема домашнє насильство й справи
щодо дітей (RISHENNYA 36.1): береться лише те, що суд уже опублікував; де
суд приховав адресу, точки немає.

## Що карта показує і чого не показує

- **Показує** місця, де правопорушення, розглянуті судом, повторюються;
  проблеми (≥ 12 подій за 2 роки), що поруч, і вулиці з умовами, схожими
  на ті, де події вже були (модель ризику).
- **Адреса — місце, де подію оформлено** в рішенні суду, а не завжди
  місце, де все сталося. Події без номера будинку на карту не йдуть.
- **Не показує причин.** Модель міряє, що поруч, а не через що сталася
  подія. Гіпотезу висуває людина на місці.
- **Не показує всього, що стається:** лише те, що дійшло до суду й
  потрапило в реєстр. Останні місяці неповні — суди розглядають справи
  із затримкою.

Як саме все рахується, з джерелом кожного правила — [METODYKA.md](METODYKA.md);
наукова основа — [NAUKA.md](NAUKA.md).

## Як відтворити

Усе збирається в GitHub Actions (`.github/workflows`), без ключів і
платних сервісів:

| Workflow | Що робить | Коли |
|---|---|---|
| Знімок OSM | файл України з Geofabrik → межа Києва + 2 км → гілка `osm` | 28-го щомісяця |
| Прохідність | модельований потік пішоходів (крок 2c) | після знімка OSM |
| Аналіз 1551 | скарги 1551 за змістом | щонеділі |
| Прохід по текстах | тексти рішень → фабула, дата й адреса події | щоночі |
| Оновлення карти | реєстр → геокодування → модель → карта → перевірка → публікація | щопонеділка; перенавчання моделі — у перший понеділок місяця |

Зламана збірка не публікується: крок `check_build` зупиняє запуск до
збереження й публікації. Прохід по текстах може (необов'язково) складати
повні тексти в окреме приватне сховище — для цього потрібен токен у
налаштуваннях репозиторію; без нього карта збирається так само.

Локально (Windows, Python 3): `py -3 src\step3_map.py` збирає карту з
даних у `data/`, `PODYVYTYSYA.bat` відкриває її на http://127.0.0.1:8777/.
Подвійним клацанням сторінка не відкривається: справи адрес лежать
окремими файлами поруч, а браузер не дає сторінці з диска їх читати.
