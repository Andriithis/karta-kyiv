## Як працювати — для будь-якого ШІ (Claude, GPT та інших)

- **Документи ніколи не суперечать одне одному** (вимога Андрія 07.10).
  Ухвалив рішення — **у тому самому коміті** приведи у відповідність усі

## Мова

Усе, що бачить користувач, і всі коментарі в коді — українською.

Коментар пояснює **чому**, а не що. «Беремо медіану, бо середнє зносить одна
вулиця з тисячею ДТП» — так. «Рахуємо медіану» — ні, це й так видно з коду.
Не переписувати чужі коментарі без причини: у них зафіксовані рішення, які
інакше доведеться приймати наново.

## Звіти Андрієві

Коротко: що зроблено, що перевірено, що потрібно від Андрія. Налагодження
по дорозі не описувати, якщо воно не міняє рішень.

## Межа, яку не можна переходити

Модель міряє, **що поруч**, а не через що сталася подія. Слова «причина»
в інтерфейсі немає навмисно. Гіпотезу про причину висуває людина на місці —
для цього поруч стоїть кнопка «Що поруч».

Не вигадувати пояснень, яких немає в даних. Краще сказати «ця вулиця не
входить до переліку ризикованих», ніж придумати правдоподібний чинник.

Адреса в подіях — з тексту рішення суду. Це місце, де подію **оформлено**, і
воно не завжди збігається з місцем, де все сталося. На карті це сказано в
атрибуції («адреси — з текстів рішень ЄДРСР»); не прибирати.

Події без номера будинку на карту не потрапляють.

На карті немає пояснювальних речень — ні в панелі, ні під перемикачами, ні в
легенді. Пояснення й позначки на кшталт «проактивний» — лише у звітах і
METODYKA.md. Якщо рішення просить щось "позначити на карті", це робиться
знаком чи кольором і лише після макета.

## Як перевіряти зміни в карті

Локально, без GitHub:

```
py -3 src\step3_map.py      (або 3-MAP.bat)
PODYVYTYSYA.bat             (підіймає http://127.0.0.1:8777/)
```

Карта — `site\index.html` (MapLibre); `site\karta-zapasna.html` — запасна
Leaflet-збірка для браузера без WebGL; `kyiv.html` і `kyiv-gl.html` —
переадресації на головну (рішення 26.09).

Подвійним клацанням карта не відкривається — панель рішень
тягне сусідній файл, а браузер із диска такого не дозволяє.

**Зміни в карті перевіряються очима, а не тільки читанням коду.** Зібрати,
відкрити, клікнути те, що міняв. Якщо змінював кольори чи переліки — звірити
на конкретних адресах, названих у завданні.

## Що не чіпати без потреби

- `src/labels.py` — словники кодів статей, 27 КБ. Стабільний файл.
- `data/` — великі файли даних. Не перезбирати й не комітити без прямої потреби.
  `data/vykluchennya.txt` збірка переписує сама — локальні зміни повертати.
- Перенавчання моделі — довге. Запускається окремою галочкою
  «Перенавчити модель ризику (крок 4)» у GitHub Actions → «Оновлення карти».
  Для змін у карті й панелі воно не потрібне.

«Оновлення карти» (кнопкою або щопонеділка; пуш сам його не запускає) і

Workflow запускаються через `gh` (встановлено й авторизовано на машині

## Правки від чатів (локальна папка і git)

Чати проєкту (центральний, «Проблеми» та інші) бачать локальну папку
`D:\problem_orienting\karta-kyiv`, але git-доступу з неї не мають. Щоб не
витрачати ліміти, вони правлять файли **в локальній папці**, а на GitHub їх
відправляє Claude Code. Правило 28.09.2026.

**Claude Code на початку кожного завдання:**
1. `git status`. Якщо є незакомічені зміни в `*.md` чи `src/`, яких ти не
   робив, — це правки чатів. Закомітити їх **окремим комітом** «Правки чату:
   <файли>» до своєї роботи. Файли з `data/` сюди не додавати (див. вище).
2. `git pull --rebase`, потім `git push`.
3. Якщо pull дав конфлікт у файлі, який правив чат, — не вирішувати
   навмання, а зупинитися й сказати Андрієві, який файл.

**Чати:**
- Читати — з локальної папки вибірково (`grep`, `sed -n` діапазон), а не
  цілі файли.
- Перед правкою перевірити, що локальна копія свіжа: `.git/refs/heads/main`
  у папці = останній коміт `main` на GitHub. Якщо відстає — правити в
  папці не можна (буде конфлікт); попросити Claude Code зробити `git pull`
  або, якщо терміново, правити через конектор GitHub.
- Правити — командою в папці (`sed -i`, коротка python-заміна), не
  передруковуючи файл.
- Git на машині Андрія не запускати: доступу немає, а обірвана команда
  лишає `.git/index.lock`, який блокує Claude Code.
- Конектор GitHub — лише для нових малих файлів або коли папка
  недоступна чи відстає. Він перезаписує файл цілком, тобто весь текст іде
  через ліміти. Великі файли (`RISHENNYA.md`) — ніколи цілком, лише через
  файл-вставку для Claude Code.
- Один файл за сесію правиться в одному місці: або в папці, або на
  GitHub. Змішування дає дві версії.
